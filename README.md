# Md. Abu Bokkor Siddik (Dex) — Portfolio

Personal portfolio website of Md. Abu Bokkor Siddik from Dhaka, Bangladesh.

- BBA student at BUBT (Bangladesh University of Business and Technology)
- Moderator at Beautyology (Facebook live sales)
- Owner of an online three-piece clothing business

## Features
- Fully dynamic single-page site: dark/light mode, live Dhaka clock with on-shift status, typewriter roles, animated counters
- Filterable skills and projects, journey timeline, services
- Contact via WhatsApp and Facebook, one-tap copy of the business number

Open `index.html` in a browser to view the site.
